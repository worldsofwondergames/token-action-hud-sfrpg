# Changelog

## 0.1.1

- A Conditions tab lists every condition the token HUD offers, as toggles for characters, NPCs and mechs. A condition the actor has is highlighted, and clicking one switches it on or off. The list is read from the Starfinder system, so conditions the system adds, such as Corrode and Frostbite, appear without a module update
- Switching on a condition that deals damage each turn, such as Corrode, asks for the amount and an optional number of rounds, the same prompt the token HUD shows
